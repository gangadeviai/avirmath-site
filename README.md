# AVIRMATH AI — website

The generated static website of **AVIRMATH AI, Open-source Ecosystem for the Mathematics behind AI**
(founder: Gangadevi, @gangadeviai). Six lesson pages with the narrated videos, captions,
chapters and the summaries written for search engines and AI assistants.

This repository holds only generated files; it is deployed as-is on Vercel. The lessons,
the verified mathematics and the architecture are in
https://github.com/gangadeviai/avirmath-ai-showcase.
